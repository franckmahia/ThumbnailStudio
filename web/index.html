QUELQUES REPÈRES, PAS UNE RECETTE

Le petit guide.

Du sujet de ta vidéo à une miniature que tu peux vraiment utiliser.

01 / LE BRIEF

Une idée claire vaut mieux que dix effets.

Indique le sujet et l’angle de ta vidéo. Le studio extrait trois accroches de ton titre, puis les met en page automatiquement. Tu peux réécrire chaque accroche.

02 / TON ABONNEMENT PRO

Ton compte ChatGPT, via Codex.

Connecte Codex avec ton compte ChatGPT dans les réglages du studio. Le bouton principal génère une image native, puis crée trois compositions. Avec un lien YouTube, Codex compose une miniature complète à partir de ton portrait de référence. Cette utilisation dépend des limites de ton abonnement. Le parcours manuel ChatGPT reste disponible.

03 / LE VISUEL

Ta photo. Ton image. Ta vidéo.

Importe une image ou sélectionne une image de ta vidéo locale. Le visuel est recadré en 16:9. Choisis un sujet placé à droite pour laisser respirer le texte à gauche.

04 / LA LECTURE

Vois petit. Pense simple.

Prévisualise ta miniature à la taille du fil YouTube. Quelques mots lisibles suffisent souvent. Une accroche doit représenter le contenu réel de la vidéo.

05 / L’EXPORT

Prête pour la prochaine étape.

Exporte en PNG ou JPG, en 1280 × 720 px. Le studio maintient le fichier sous 2 Mo. Après import d’un lien YouTube, vérifie ton visage, génère puis valide l’aperçu exact. Le bouton Installer envoie uniquement le fichier validé à la chaîne connectée. La connexion Google se configure dans Mon studio.

06 / TES CRÉATIONS

Un studio local, à garder sous la main.

Les projets et images restent dans le stockage de ce navigateur. Pense à exporter un projet JSON pour en garder une sauvegarde complète. Effacer les données du navigateur efface la bibliothèque.

Connecte la chaîne qui possède tes vidéos pour installer les miniatures validées.

Configurer Google, étape par étape
  1. Dans Google Cloud ↗, crée ou sélectionne un projet.
  2. Active YouTube Data API v3 ↗ pour ce projet.
  3. Dans Google Auth Platform, configure l’audience et l’écran de consentement. En mode test, ajoute ton adresse Google parmi les utilisateurs test.
  4. Crée un client OAuth de type Application de bureau, puis télécharge son fichier JSON.
  5. Importe ce fichier ci-dessous, puis clique sur Connecter YouTube. Choisis la bonne chaîne et autorise les accès demandés.

En mode test Google, la connexion peut expirer après 7 jours : reconnecte simplement YouTube. Le fichier client et les jetons restent dans le dossier privé du studio, hors de la bibliothèque et des sauvegardes de projets.
